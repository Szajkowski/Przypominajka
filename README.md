# Przypominajka

## Description
A desktop reminder application built with Python and PyQt6 designed to keep track of daily tasks, upcoming dates, and yearly recurring events (e.g., birthdays or anniversaries). The app features a customizable interface with dark/light mode toggles and dynamic color themes, automatically saving all persistent data locally in JSON format.

## Key Features
- Today's Summary Dashboard: Displays all events scheduled for the current date immediately upon startup.
- Flexible Event Management: Built-in event manager with an interactive calendar selector for scheduling annual recurring events, single-occurrence non-persistent events (auto-deleted after display), and standard single-occurrence events.
- Custom Visual Themes: Support for multiple accent colors (Purple, Red, Blue, Green, Pink, Orange, Yellow, Gray) combined with Dark and Light mode toggles.
- Persistent Local Storage: Automatically saves events, active theme settings, and UI mode preferences in a local JSON database file.
